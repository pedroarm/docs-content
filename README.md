# docs-content

Conteúdo da documentação da equipe técnica, em Markdown. O site lê este repositório diretamente: o que entra na branch `main` é publicado em segundos.

- As páginas ficam em `docs/`, uma pasta por área.
- O guia de escrita está em [`docs/onboarding/como-contribuir.md`](docs/onboarding/como-contribuir.md).
- Para revisar uma mudança antes de publicar, crie uma branch e abra `/preview/nome-da-branch` no site.

Este repositório é público. Não inclua senhas, chaves de transmissão ou dados pessoais.
