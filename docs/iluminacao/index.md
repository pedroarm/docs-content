Esta é a área de **Iluminação**. Use o menu para navegar:

- **Procedimentos**: checklists do que fazer antes, durante e depois do culto.
- **Solução de problemas**: páginas curtas no formato "aconteceu X, faça Y".
- **Equipamentos**: manual de cada equipamento que a equipe opera.

<Callout type="warn" title="Conteúdo de exemplo">
As páginas desta área são modelos. Substitua o texto entre colchetes pelo procedimento real da igreja.
</Callout>
