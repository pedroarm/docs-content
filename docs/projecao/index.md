Esta é a área de **Projeção**. Use o menu para navegar:

- **Procedimentos**: checklists do que fazer antes, durante e depois do culto.
- **Solução de problemas**: páginas curtas no formato "aconteceu X, faça Y".
- **Equipamentos**: manual de cada equipamento que a equipe opera.
